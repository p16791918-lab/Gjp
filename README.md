```

│   ├─ make_해설_YYYY_N교시.py # 해설 생성기 (30개)

├─ data_해설/             # 해설 JSON 데이터 (빈출 집계용)
├─ legacy/                # 옛 분석 스크립트·PDF (현재 학습노트로 대체됨)

└─ README.md
```

## 실행법 (반드시 저장소 루트에서 실행)

스크립트는 입력(`figures/`, `diagrams/`, `data_해설/`)과 출력 경로를 **현재 작업 디렉터리(루트) 기준**으로 참조한다. 항상 루트에서 실행할 것.

```bash
# 해설 PDF 재생성 (→ 해설_pdf/)
python3 scripts/make_해설_2022_1교시.py

# 학습노트 PDF 재생성 (→ 학습노트_pdf/)
python3 scripts/make_학습노트_3교시.py

# 개념 도해 전체 재생성 (→ diagrams/)
python3 scripts/make_diagrams.py

# 사진 PDF에서 그림 추출 (→ figures/)
python3 scripts/extract_figures.py 문제/2021/2021_기종평_사진_1교시.pdf 2021_1
```

한글 폰트 NanumGothic 필요: 없으면 `apt-get install -y fonts-nanum`.
